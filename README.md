## ✨ Features
- 🌗 **Dark and Light Themes**: Seamlessly switch between modes.
- 🌍 **Localization**: Supports English and Arabic.
- 📖 **Quran and Hadith Modules**: Read and search with ease.
- 🧮 **Sebha Counter**: Track your tasbih counts.
- 🎧 **Quran Radio**: Listen to Quran recitations.
